# Lenkų kalba

Lenkų kalbos programėlė pradedantiesiems lietuviams. 10 pamokų nuo lengviausių (tarimas, pasisveikinimai, prisistatymas, skaičiai, kavinė, parduotuvė, miestas, šeima, darbas, dienos). Kiekvienoje pamokoje yra trumpas gyvas dialogas, žodžiai, gramatikos pastaba lietuviškai ir pratybos: pasirinkti vertimą, atpažinti iš klausos, parašyti lenkiškai, sudėlioti sakinį, įrašyti praleistą žodį.

Žodžiai kartojami su intervalais (1, 2, 4, 8, 16… dienų). Galima pridėti savo žodžių, pvz. iš [polski.info](https://polski.info/?hl=lt) pamokų.

Garsas: telefono kalbos sintezė (lenkiškas balsas, pl-PL).

Atidaryti: https://arnoldasbud.github.io/Lenk-kalba/

Viskas viename `index.html` faile, be priklausomybių. Pažanga saugoma naršyklėje (localStorage). Veikia be interneto (`sw.js`). Versija keičiama `index.html` (`VERSION`) ir `version.json`.
